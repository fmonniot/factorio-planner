Summary detail strip: icon actions

When an item is selected in a summary pane, its detail strip has more to show than the pane can hold. Products and Byproducts run their buttons under the next pane. Ingredients stack seven lines in a strip that is never shorter than 156 px. This spec gives the three panes one pattern: an icon-only toolbar on a single row, with the same icon button, the same tooltips and the same order of meaning, and the Comes from block of Ingredients folded into that row. Each section has a replica built at the real pane widths, the exact controls to build, and the checks that say it is done.

One pattern for all three panes build this once, use it three times

The three strips share one toolbar component. The rules below hold in every pane; the sections after this one only list which controls each pane puts in it.

Toolbar
One row, 22 px high, icon buttons only (24 × 22 px), 4 px between them, never wrapping, no text labels. Same row in the selected state and in the preview state.
Order of meaning
Left: ways to make or supply the item (Find recipe, Receive from…, Add consumer recipe…). Middle, Ingredients only: the rule group (three presets, Import, Leftover), between two separators. Right, after the spacer: information first (Served order…, Sources…), then changes to the block, with the most destructive at the far edge (Remove product, Make it a product).
Same meaning, same icon
An icon means one thing in every pane: the magnifier is always "find a recipe", the list is always "served order", the two arrows are "receive from another block" (pointing in) and "add a block that consumes this" (pointing out). No icon is reused for a different action.
Name and tooltip
The accessible name is the action's name. The tooltip (data-tip, the app's instant tooltip) is the same text, unless the action already has a longer help text, which it keeps.
States
Lit (teal) for a chosen preset and an on switch. Disabled at 40% opacity with the reason as tooltip. A count badge on the top right corner. Red for Remove product only.
Height
Products and Byproducts strips stay 72 px. The Ingredients strip is content-sized, because it also carries the sentence.

Conditional rows: proposed placement

Three parts of ComesFrom show in the strip only in some cases. They were not part of the icon decision. The proposal is to keep them as text, in today's order, under the controls row, so they add height only when present. Tick "Show the conditional rows" above to see all three at once, which is the worst case: the strip is then 151 px at 413 px and 193 px at 260 px. Today's strip would grow by the same rows on top of its 194 px and 227 px.

Open decisions

Settled for this spec unless the owner says otherwise. Each has a default the implementer can build.

1. Touch. TooltipLayer never opens on touch, so on a phone the icons have an accessible name but no visible label. The backlog already tracks hover-only and right-click-only gaps. Default: ship it that way and address touch with the rest of that backlog item. The right-click menu on a slot keeps the full text list of actions, so nothing is unreachable.
2. Legibility of the icons. The least guessable are Make it a product (flag), Use it all here (flame), Leftover (arrow out of a tray) and the pair of arrows, Receive from… (in) and Add consumer recipe… (out). Default: keep them all as icons, since the same tooltip and the same icon in every pane is the consistency the owner asked for. If some read badly in use, change that icon or give that one action a text label in all the panes that have it, never in one pane only.
3. Conditional rows. Placement above is a proposal; the owner has not looked at it in a real strip. Default: as shown.

Acceptance checks

  • With a middle product that has an extra output and a Served order badge selected, the toolbar of the Products pane does not overflow at pane widths 260, 333, 413 and 467 px, and the Byproducts and Ingredients toolbars do not at 260 px.
  • All three toolbars use the same icon button (24 × 22 px, 4 px gap) with no text labels, the same icon for the same action in every pane, and the order of the pattern: make or supply on the left, information then changes on the right.
  • The selected strip of Products and Byproducts is 72 px high in the selected, preview and editing states.
  • Every icon button has an accessible name equal to the tables above, and a tooltip. A disabled one shows its reason on hover.
  • Tab order is the visual order. The presets are one tab stop; the arrow keys move and choose.
  • The Served order icon opens the existing popover and carries the badge with the name Served order… · N not ranked; Escape returns focus to it.
  • The selected Ingredients strip has no minimum height and is at most 108 px with a one or two line sentence at 260 px wide, with no horizontal overflow.
  • Changing a preset, Import or Leftover from the icon row has the same effect as today, and the sentence under the bar updates.
  • The Comes from popover (opened for an item without a slot) is unchanged.
  • The existing unit and e2e tests pass, with queries by visible text updated.
